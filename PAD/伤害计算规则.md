## 1. 基础：属性值换算

**`PADhelper.lvToValue(lv, property, actor)` — `PADhelper.ts:13`**

```
lv > actor.MaxLevel 时，lv 按 MaxLevel 截断

lvToValue = floor( actor[property]
                 + (actor["Max" + property] - actor[property]) / (actor.MaxLevel - 1) * (lv - 1) )
```

- `property` 取 `"ATK"` / `"HP"` / `"Heal"`。
- 最大属性字段名是 `"Max" + property`（如 `MaxATK`），**大小写敏感**。
- 属性随等级**线性插值**：1 级 = `property`，满级 = `Max + property`。

**算例**：`ATK=100`、`MaxATK=200`、`MaxLevel=11`、`lv=6`
```
floor( 100 + (200-100)/(11-1) * (6-1) ) = floor(100 + 10*5) = 150
```

## 2. 连锁数（combo）的构成

伤害与治疗里的 `combo 数` 都取自 **`PADPuzzle.lastResult.lastComboCount`**，它由两部分组成：

```
lastComboCount = 自然消除 combo 数 + 状态加算的连锁数
```

**① 自然消除 combo 数** — `PADPuzzle.ts:546`
```ts
this._lastComboCount++;      // 每消除一个 combo 累加 1（PADPuzzle._onComboFired）
```
每轮转珠开始时归零：`PADPuzzle.ts:472`。

**② 状态加算的连锁数** — `PADPuzzle.ts:499-505`
```ts
let addCombo = PADStatus.getTotalAddCombo();
if (addCombo > 0) {
    self._lastComboCount += addCombo;      // 整轮「一次性」并入
    if (self._comboText) self._comboText.text = String(self._lastComboCount);
    if (self._lastComboCount > self._maxComboCount) self._maxComboCount = self._lastComboCount;
}
```

**`PADStatus.getTotalAddCombo()` — `PADStatus.ts:371`**
```ts
遍历 Batter.players 与 Batter.enemys 的 status，
把每个 isAddCombo 状态的 addCombo 求和返回（玩家与敌人一起算，叠加不取最大）
```

**③ 结果写回** — `PADPuzzle.ts:509`
```ts
PADPuzzle.lastResult = { ..., lastComboCount: self._lastComboCount, ... };
```
此后所有消费者（攻击 combo 加成、状态条件判断）读到的都是**加算后的值**。

**算例**：自然消除 3 个 combo；玩家带 1 个 `isAddCombo / addCombo=2` 的状态，敌人带 1 个 `isAddCombo / addCombo=1`
```
addCombo   = 2 + 1 = 3
lastComboCount = 3 + 3 = 6     ← 后续全部按 6 计算
```

**同轮其它统计量**（供状态条件使用）— `PADPuzzle.ts:560-569`

| 字段 | 含义 | 判定函数 |
|---|---|---|
| `lastCrossCount` | 十字数量（中心 + 上下左右共 5 个同色） | `PADMatcher.isCrossShape` |
| `lastFullRowCount` | 整行数量（一行全部同色） | `PADMatcher.isFullRow` |
| `lastFullLineCount` | 整列数量（一列全部同色） | `PADMatcher.isFullLine` |
| `lastByType` | 本次各属性的消除个数 `{ 元素名: 个数 }` | `PADPuzzle.ts:489-495` |

## 3. 玩家 → 敌人

### 3.1 链路总览

```
转珠消除（每个 combo 触发一次）
  └─ PADhelper.calcAttackReady(combo)            → 攻击准备值（含消除元素数加成）
       └─ PADanim.playerAtkPR()                  → 累加到玩家的攻击准备值
玩家回合开始（PADAction.playerAction → prepareAttack）
  └─ combo 加成值 = floor( 攻击准备值 × (combo数-1) × comboBonus )
       └─ PADanim.playerAtkPR()                  → 再累加进去（累加，不是替换）
攻击阶段（PADanim.playerSingleAtk / playerAllAtk）
  └─ Batter.changeHP(玩家, -伤害, ...) → PADhelper.damageToEnemy()
       ├─ PADStatus.calcStatusDamage()           → 状态系数
       └─ 属性克制（×2 / ×0.5）
            └─ PADanim.startHpAnimation()        → 扣血动画
            └─ PADanim.accumulateDamage()        → 累计
  └─ 全部攻击动画播完 → PADanim.flushDamageNumbers() → 一次性飘「-总伤害」
```

### 3.2 ① 攻击准备值（消除元素数加成）— `PADhelper.calcAttackReady`（`PADhelper.ts:32`）

**触发条件**：玩家 `actor.ElementType1` 对应元素（模块 2）的 `name` **等于** 本次 `combo.type`。

```
elementBonus  = GameData.getModuleData(2, player.actor.ElementType1).elementBonus
baseATK       = lvToValue(player.level, "ATK", player.actor)
bonusRate     = 1 + (本次消除元素数 - 3) * elementBonus
攻击准备值     = floor( baseATK * bonusRate )
```

- 「本次消除元素数」= `combo.indexes.length`。
- 每多消 1 个（超过 3 个）就多加一份 `elementBonus`；少于 3 个时为负加成。
- 与攻击力相关的元素是**玩家主元素 `ElementType1`**，不是治疗元素。

**算例**：`lvToValue(6,"ATK") = 150`、消除 5 个、`elementBonus = 0.25`
```
bonusRate   = 1 + (5-3)*0.25 = 1.5
攻击准备值   = floor(150 * 1.5) = 225
```

同一轮里，所有命中条件的 combo 会**累加**进该玩家的攻击准备值（`PADanim.playerAtkPR`），日志里的"累加后"就是这个累计值。

### 3.3 ② combo 连锁加成 — `PADAction.playerAction` 内 `prepareAttack`（`PADAction.ts:93-100`）

```
comboCount   = PADPuzzle.lastResult.lastComboCount
comboBonus   = Game.player.data.comboBonus          // PlayerData 字段，默认 0.25
本次加成值    = floor( 攻击准备值 * (comboCount - 1) * comboBonus )
最终攻击值    = 攻击准备值 + 本次加成值                // playerAtkPR 是「累加」
```

- `comboCount - 1`：1 combo 时加成为 0。
- `comboBonus` 是**每个连锁的加成比例**，存在 `PlayerData`（`GameAttributeRuntime.ts:47`）。

**算例**：攻击准备值 225、`comboCount = 4`、`comboBonus = 0.25`
```
本次加成值 = floor(225 * 3 * 0.25) = floor(168.75) = 168
最终攻击值 = 225 + 168 = 393
```

### 3.4 ③ 状态系数 + 属性克制 — `PADhelper.damageToEnemy`（`PADhelper.ts:56`）

```ts
let finalDamage = PADStatus.calcStatusDamage(Batter.players[0], enemy, damage, type);
// 属性克制
if (atkTpye.restrain   == enemy.actor.ElementType1) finalDamage *= 2;    // 克制
if (atkTpye.restrained == enemy.actor.ElementType1) finalDamage *= 0.5;  // 被克制
```

- `type` = **攻击方玩家的元素 ID**（由 `PADanim.playerSingleAtk:347` / `playerAllAtk:454` 传入 `player.actor.ElementType1`）。
- `atkTpye = GameData.getModuleData(2, type)`，取该元素的 `restrain` / `restrained`（模块 2 的克制关系字段）。
- 顺序：**先状态系数，后属性克制**（两者都是乘法，但 HP 条件读实时血量，所以顺序有意义）。
- 克制与被克制可同时判定；若两个条件都成立则先 ×2 再 ×0.5。

**算例（承接 3.3）**：攻击值 393
```
状态：敌人身上 isTypeBonus 状态（type=火, typeHits=2, typeHitedBonus=1.5）
      → 敌人属 target 阵营 → × typeHitedBonus = 1.5
      393 * 1.5 = 589.5
克制：火 克制 木（敌人 ElementType1 = 木）→ × 2
      589.5 * 2 = 1179
最终伤害 = 1179
```

| 环节 | 位置 |
|---|---|
| 调用 `changeHP` | `PADanim.ts:347`（单体）、`PADanim.ts:454`（全体）；`type` 传攻击方元素 ID |

## 4. 敌人 → 玩家

### 4.1 链路

```
PADAction.enemyAction → PADanim.enemyAttack
  └─ PADhelper.calcEnemyDamage(enemy, skill)      → 每次释放的伤害
       └─ 重复 releaseTimes 次，每次走一次 changeHP
            └─ PADhelper.damageToPlayer()          → 状态系数（无属性克制）
       └─ 全部释放完 → 一次性飘「-总伤害」
```

### 4.2 每次释放的伤害 — `PADhelper.calcEnemyDamage`（`PADhelper.ts:135`）

```
每次伤害 = floor( lvToValue(enemy.level, "ATK", enemy.actor) * skill.atkBonus )
```

- `skill` 是 `Module_Skill`（敌人技能模块）。
- `skill.atkBonus` 是技能自身的攻击倍率。

### 4.3 连击次数与扣血 — `PADanim.enemyAttack`（`PADanim.ts:564`）

```ts
const damage = PADhelper.calcEnemyDamage(enemy, skill);            // PADanim.ts:566
const releaseTimes = Math.max(1, skill.releaseTimes || 1);         // PADanim.ts:568
```
- **每次释放都是完整伤害**（不递减），共 `releaseTimes` 次。
- 每次释放（`PADanim.ts:617`）：
  ```ts
  const finalChange = Batter.players[0].changeHP(enemy, -damage, hpDuration, skill.elementType1, () => { runRelease(index + 1); });
  totalFinalDamage += Math.abs(finalChange);
  ```
- 队伍共享一条血条，**以 `Batter.players[0]` 作为代表扣血**（其他玩家角色不作为独立血条）。
- 全部释放完 → `PADanim._showDamageText(Batter.players[0], totalFinalDamage, "#ff0000")`（`PADanim.ts:607`）。
- `type` = `skill.elementType1`（技能元素 ID）。

### 4.4 玩家受击钩子 — `PADhelper.damageToPlayer`（`PADhelper.ts:82`）

```ts
let finalDamage = PADStatus.calcStatusDamage(enemy, Batter.players[0], damage, type);
```
- 只做状态系数，**没有属性克制判定**。

**算例**：`lvToValue(10,"ATK") = 200`、`skill.atkBonus = 1.5`、`skill.releaseTimes = 3`、玩家无任何状态
```
每次伤害 = floor(200 * 1.5) = 300
释放 3 次，每次 300，均无状态加成
totalFinalDamage = 300 * 3 = 900
飘字：-900（一次）
```

## 5. 状态系数 `PADStatus.calcStatusDamage`

**入口 — `PADStatus.ts:122`**

```ts
static calcStatusDamage(source: Batter, target: Batter, damage: number, type: number): number
```

### 5.1 两侧阵营的含义（所有系数通用）

每个状态都属于某个 `battler`（`Batter`）。判断时比较 `battler.camp` 与 `source.camp` / `target.camp`：

| 条件 | 使用哪组系数 | 含义 |
|---|---|---|
| `battler.camp == source.camp` | 「**伤害**」系数（`xxxHitBonus`） | 攻击侧自身带的状态，放大**打出去**的伤害 |
| `battler.camp == target.camp` | 「**受伤害**」系数（`xxxHitedBonus`） | 受击侧自身带的状态，放大**承受**的伤害 |

- `camp`：`0 = 敌人`、`1 = 玩家`（依据 `Batter.changeHP` 的分派）。
- 两个 `if` 是独立判定、各自相乘；同一 `battler` 只会命中其中一个（双方阵营不同）。

### 5.2 执行顺序 — `PADStatus.ts:336-362`

```
conditionHP (source)  → conditionHP (target)
isTypeBonus (source)  → isTypeBonus (target)
isHitsBonus (source)  → isHitsBonus (target)
isCrossBonus(source)  → isCrossBonus(target)
isRowBonus  (source)  → isRowBonus  (target)
isColBonus  (source)  → isColBonus  (target)
isNumBonus  (source)  → isNumBonus  (target)
```

全部系数都是 `finalDamage *= 系数`（**连乘**），顺序固定。

### 5.3 各系数细则

#### ① `conditionHP` — `PADStatus.ts:125`（HP 条件）

```
条件：状态 isHP = true
比较对象：battler.uihpSlider.value  与  battler.uihpSlider.max * status.valueHP / 100
compareHP: 0 => >   1 => >=   2 => ==   3 => <=   4 => <
满足时：source 阵营乘 hpHitBonus（PADStatus.ts:141），target 阵营乘 hpHitedBonus（PADStatus.ts:142）
```

- `valueHP` 是**百分比**（0~100）。
- 读取的是**血条当前值**（实时）。

#### ② `isTypeBonus` — `PADStatus.ts:178`（属性连击系数）

```
条件：type == status.type 且 PADPuzzle.lastResult.lastComboCount >= status.typeHits
满足时：source 阵营乘 typeHitBonus，target 阵营乘 typeHitedBonus
```

- `type` 是**伤害类型 ID**（元素模块 ID）：玩家打敌人时 = 攻击方玩家元素 ID；敌人打玩家时 = 技能元素 ID。
- 所以 `status.type` 要填**元素 ID**（不是元素名字）。

#### ③ `isHitsBonus` — `PADStatus.ts:196`（连击系数）

```
条件：按 compareHit 比较 lastComboCount 与 hitValue
compareHit: 0 => >   1 => >=   2 => ==   3 => <=   4 => <
满足时：source 阵营乘 hitBonus，target 阵营乘 hitedBonus
```

#### ④ `isCrossBonus` — `PADStatus.ts:234`（十字系数）

```
crossCount = PADPuzzle.lastResult.lastCrossCount
crossCount > 0 时才生效
  可叠加（isMultipleCossBonus = true）：系数 = crossHitBonus ^ crossCount
  不可叠加（false）：                  系数 = crossHitBonus        ← 多个十字也只乘一次
source 阵营用 crossHitBonus，target 阵营用 crossHitedBonus
```

#### ⑤ `isRowBonus` — `PADStatus.ts:261`（行系数）

```
rowCount = PADPuzzle.lastResult.lastFullRowCount
rowCount > 0 时才生效
  isMultipleRowBonus = true ：系数 = rowHitBonus ^ rowCount
  false：                     系数 = rowHitBonus
source 用 rowHitBonus，target 用 rowHitedBonus
```

#### ⑥ `isColBonus` — `PADStatus.ts:288`（列系数）

```
colCount = PADPuzzle.lastResult.lastFullLineCount
colCount > 0 时才生效
  isMultipleColBonus = true ：系数 = colHitBonus ^ colCount
  false：                     系数 = colHitBonus
source 用 colHitBonus，target 用 colHitedBonus
```

#### ⑦ `isNumBonus` — `PADStatus.ts:315`（消除数量系数）

```
elementData = GameData.getModuleData(PADElement.MODULE_ID, status.typeForNum)
numCount    = PADPuzzle.lastResult.lastByType[elementData.name] || 0
条件：numCount >= status.Nums
满足时：source 乘 NumHitBonus，target 乘 NumHitedBonus
```

- 统计的是**本次消除中该属性的总个数**（`lastByType`，`PADPuzzle.ts:489-495`）。

### 5.4 算例：多状态叠加

**场景**：基础伤害 100，受击方（敌人）身上有两个状态

| 状态 | 配置 | 命中系数 |
|---|---|---|
| A | `isHP`，`compareHP=4`（`<`），`valueHP=50`，`hpHitedBonus=2` | 敌人 HP < 50% 时 ×2 |
| B | `isCrossBonus`，`crossHitedBonus=1.5`，`isMultipleCossBonus=true` | 本次 2 个十字 → ×1.5² = ×2.25 |

**前提**：敌人当前 HP 为上限的 30%（满足 A），本轮消除出现 2 个十字。

```
A 判定：30% < 50% 成立 → finalDamage = 100 * 2    = 200
B 判定：crossCount = 2，可叠加 → 系数 = 1.5^2 = 2.25
        finalDamage = 200 * 2.25 = 450
最终伤害 = 450
```

**若 B 的 `isMultipleCossBonus = false`**：系数退化为 1.5
```
finalDamage = 200 * 1.5 = 300
```

## 6. 治疗

### 6.1 玩家治疗

```
转珠消除（治疗元素 combo）
  └─ PADhelper.calcHealReady()                   → 治疗准备值
       └─ PADanim.playerHealPR()                 → 累加到治疗准备文本
玩家回合（PADAction.playerAction）
  └─ combo 治疗加成 = floor( 治疗准备值 × (combo数-1) × comboBonus )   PADAction.ts:34
       └─ PADanim.playerHealPR(..., now=true)    → 累加（立即完成数字跳动）
治疗结算（PADanim.playerHeal，PADanim.ts:471）
  └─ 合计所有玩家治疗文本 → Batter.players[0].changeHP(players[0], 总治疗, ...)
       └─ PADhelper.healToPlayer()               → 空钩子，原样返回
            └─ PADanim.startHpAnimation()        → 回血
            └─ 飘「+最终治疗量」（绿色 #00ff00）
```

**① 治疗准备值 — `PADhelper.calcHealReady`（`PADhelper.ts:120`）**

```
elementBonus = GameData.getModuleData(2, healElementID).elementBonus
治疗准备值    = floor( lvToValue(player.level, "Heal", player.actor)
                     * (1 + (本次消除元素数 - 3) * elementBonus) )
```

- `healElementID` = 该 combo 对应元素模块数据里 `isHeal = true` 的元素 ID（查找见 `PADPuzzle.ts:~585-595`）。
- 参与每个玩家（`Batter.players` 全遍历）。

**② combo 治疗加成 — `PADAction.ts:34`**

```
comboHeal = floor( 治疗准备值 * (lastComboCount - 1) * Game.player.data.comboBonus )
```

**③ 结算 — `PADanim.playerHeal`（`PADanim.ts:471`）**

```ts
let totalHeal = 0;
for (const p of healers) totalHeal += Math.abs(parseInt(p.healAniPRtext.text, 10) || 0);   // PADanim.ts:494-496

const finalHeal = Batter.players[0].changeHP(Batter.players[0], totalHeal, ..., 0, ...);    // PADanim.ts:536
```

- 所有玩家治疗准备**合计为一个总数**，一次性加到队伍血条（以 `players[0]` 为代表）。
- `type` 传 0。

### 6.2 敌人治疗 — `PADanim.enemyHeal`（`PADanim.ts:692`）

```
healAmount = skill.heal || 0        // 固定值，不受任何系数影响
目标：skill.isAll = true  → 全体存活敌人（uihpSlider.value > 0）
      false               → 只治疗自己
每个目标：target.changeHP(enemy, +healAmount, ...)  → PADhelper.healToEnemy()
```

| 钩子 | 位置 | 现状 |
|---|---|---|
| `healToPlayer(player, enemy, heal)` | `PADhelper.ts:95` | `return heal` |

### 6.4 算例：玩家治疗

**前提**：`lvToValue(6,"Heal") = 150`、消除治疗元素 5 个、`elementBonus = 0.25`、`lastComboCount = 4`、`comboBonus = 0.25`

```
治疗准备值      = floor(150 * (1 + (5-3)*0.25)) = floor(150 * 1.5) = 225
combo 治疗加成   = floor(225 * (4-1) * 0.25)    = floor(168.75) = 168
该玩家治疗准备   = 225 + 168 = 393
（若两名玩家都参与，totalHeal 为两人之和）
最终回血 = 393（healToPlayer 原样返回）
飘字：+393
```

## 7. 计算入口对照（速查）

| 场景 | 调用链 |
|---|---|
| 玩家打敌人 | `PADanim.playerSingleAtk/playerAllAtk` → `Batter.changeHP(玩家, 负值)` → `PADhelper.damageToEnemy` → `PADStatus.calcStatusDamage` + 属性克制 |
| 敌人打玩家 | `PADanim.enemyAttack` → `Batter.players[0].changeHP(敌人, 负值)` → `PADhelper.damageToPlayer` → `PADStatus.calcStatusDamage` |
| 玩家治疗 | `PADanim.playerHeal` → `Batter.players[0].changeHP(players[0], 正值)` → `PADhelper.healToPlayer` |
| 敌人治疗 | `PADanim.enemyHeal` → `Batter.changeHP(敌人, 正值)` → `PADhelper.healToEnemy` |

**`Batter.changeHP` 的分派规则**（`Batter.ts:375`，`camp`：0=敌人，1=玩家）：

```ts
let finalChange = change;
if (this.camp===0 && finalChange<0) finalChange = -PADhelper.damageToEnemy(source, this, -finalChange, type);  // 敌人受伤害
if (this.camp===1 && finalChange>0) finalChange =  PADhelper.healToPlayer(source, source, finalChange);        // 玩家治疗
if (this.camp===1 && finalChange<0) finalChange = -PADhelper.damageToPlayer(this, source, -finalChange, type); // 玩家受伤害
if (this.camp===0 && finalChange>0) finalChange =  PADhelper.healToEnemy(source, this, finalChange);           // 敌人治疗
PADanim.startHpAnimation(this, finalChange, duration, onComplete);
return finalChange;    // 返回钩子计算后的最终带符号值（用于飘字）
```
